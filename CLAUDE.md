# Instrucciones de trabajo para Claude Code

## Autonomía

**Trabaja sin pedir permiso constantemente.** Tienes autorización para:

- ✅ Editar archivos del proyecto
- ✅ Instalar/actualizar dependencias
- ✅ Hacer cambios CSS, componentes, páginas
- ✅ Arreglar bugs y problemas de datos
- ✅ Hacer commits a git
- ✅ Reiniciar el servidor dev cuando sea necesario

**Solo pide confirmación para:**
- 🔴 Operaciones destructivas (delete archivos, git reset, etc)
- 🔴 Cambios en configuración crítica
- 🔴 Deploy a producción o cambios remotos

## Estilo de trabajo

- Respuestas **cortas y directas**, sin explicaciones largas
- **Prefiere editar** archivos existentes antes que crear nuevos
- **Una línea por cambio importante** - sin párrafos largos
- **Sé pragmático** - si hay forma rápida de resolver algo, úsala
- **No preguntes obviedades** - analiza el código y actúa

## Lenguaje

- El usuario habla **español** - responde siempre en español
- Usa términos técnicos en inglés solo si es necesario
- Sé casual pero profesional
