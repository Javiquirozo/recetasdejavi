# Vlog de Javi - Recetas Veganas

Sitio web moderno para 167 recetas veganas deliciosas y nutritivas.

## 🚀 Tech Stack

- **Framework:** Astro 6.x
- **Styles:** Tailwind CSS
- **Typography:** Poppins + Inter (Google Fonts)
- **Hosting:** Netlify
- **Data:** JSON (recetas-procesadas.json)

## 🎨 Branding

- **Color Primario:** #9a659b (Morado)
- **Color Secundario 1:** #bcc65e (Verde limón)
- **Color Secundario 2:** #6bb29c (Verde agua/Turquesa)
- **Dark Mode:** Activado ✅

## 📁 Estructura

```
src/
├── pages/          # Rutas principales
├── components/     # Componentes reutilizables
├── layouts/        # Layouts
├── data/           # Datos JSON
└── styles/         # CSS global

public/images/      # Imágenes estáticas
```

## 🚀 Instalación

```bash
npm install
npm run dev       # Desarrollo
npm run build     # Producción
npm run preview   # Vista previa
```

## 📝 Contenido

- **167 Recetas:** Platos principales, postres, bebidas, entradas, etc.
- **Búsqueda:** Por nombre
- **Filtros:** Por categoría y dificultad
- **Blog:** Artículos de salud y nutrición
- **Sobre mí:** Biografía y fotos
